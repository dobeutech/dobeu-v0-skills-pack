Curated agent skills for v0.app and other skills.sh-compatible agents,
maintained by Dobeu Tech Solutions LLC (dobeu.net).

Install everything via the team pack: `npx skills add https://skills.sh/p/<pack-id>`
(pack id filled in after creation — see PACK-SETUP.md), or install this repo directly:
`npx skills add <github-owner>/dobeu-v0-skills-pack`.
